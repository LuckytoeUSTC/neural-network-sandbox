# 神经网络沙盒

把一群神经元连起来，给它们一些刺激，看看活动会怎样变化。

这是一个在浏览器里运行的小型神经科学实验工具。你可以改变神经元的模型、连接方式和输入，观察活动如何在网络中传播，也可以只记录其中一部分，看看自己能从有限的观测里发现什么。

## 可以从哪里开始？

选一个预设，先看看它自己会怎样运行，再改一个你感兴趣的条件。比如：

- 把一条单向连接的链闭合成环，一次短暂的刺激之后，会有什么不同？
- 网络不变，只改变刺激的位置或强度，哪些神经元的活动会受影响？
- 同一张网络，记录全部神经元和只记录少数几个时，看到的相关性有什么不同？观察得更久，会改变判断吗？

预设只是起点，你也可以自己指定连接矩阵和刺激，把两次实验的结果放在一起比较。

## 能看到什么？

你可以沿着时间看单个神经元的活动，播放整张网络的变化，也可以查看群体活动、协方差及其特征值。连接图、活动曲线和统计结果来自同一次模拟，可以相互对照。

模型包括 rate models 和 LIF，连接结构可以是环、链、随机网络或自定义网络。记录既可以选取具体神经元，也可以用随机投影观察多个神经元活动的混合。模型方程、假设和这些观测方式的含义，都放在程序里的 **Models & methods** 中，提供中英文说明。

## 下载使用

**[下载离线版](https://github.com/LuckytoeUSTC/neural-network-sandbox/releases/latest/download/neural-network-sandbox-offline.zip)**

完整解压，用 **Chrome 或 Edge** 打开文件夹里的 **`index.html`**，就可以开始。不需要安装软件或联网；请保留同一文件夹中的其他文件。

界面为英文，模型说明默认中文。想留下实验，可以导出配置和数据；关闭或刷新页面前记得保存。
