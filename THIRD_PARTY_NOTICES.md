# Third-party components

The downloadable offline distribution bundles MathJax 4.1.3 and MathJax-Newcm font components 4.1.3 under `vendor/mathjax/4.1.3/`.

- MathJax: https://github.com/mathjax/MathJax — Apache License 2.0; see `vendor/mathjax/4.1.3/LICENSE`.
- MathJax-Newcm: https://github.com/mathjax/MathJax-fonts — Apache License 2.0; see `vendor/mathjax/4.1.3/fonts/mathjax-newcm-font/LICENSE`.

The local loader is in `vendor/mathjax/local-mathjax.js`. This application ships the SVG renderer and the locally installed extensions/font assets used by its documentation, not the full MathJax development package.
